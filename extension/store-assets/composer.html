Skyreader — Chrome Web Store screenshot composer

Each frame is a 1280×800 canvas (the store's required size, exported opaque PNG — no alpha). Capture your popup with DevTools right-click → Inspect (keeps it open) then right-click the <body> → Capture node screenshot. Drop that PNG onto a frame, or drop the files named save.png / discover.png / standard.png / saved.png into a shots/ folder next to this file and reload to auto-fill. Edit the FRAMES array in this file to change headlines.

Popups render sharpest when the screenshot is at least 640px wide (a 2× retina capture of the 320px popup).
