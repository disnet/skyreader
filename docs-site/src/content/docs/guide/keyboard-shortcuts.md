---
title: Keyboard shortcuts
description: Move through your reading, open views, and act on articles without the mouse.
---

On a computer, most of Skyreader works from the keyboard. Press `?` anywhere to see the list in the app. Shortcuts stay out of the way while you're typing in a box.

## Moving around

| Key     | Does                                                       |
| ------- | ---------------------------------------------------------- |
| `j`     | next item                                                  |
| `k`     | previous item                                              |
| `Enter` | expand or collapse the item                                |
| `f`     | read the item full screen                                  |
| `o`     | open the original in a new tab                             |
| `[`     | previous feed                                              |
| `]`     | next feed                                                  |
| `g`     | open the view switcher                                     |
| `/`     | open [search](/guide/search/) (Supporter), or the switcher |

## Going to a view

| Key | Opens                                                            |
| --- | ---------------------------------------------------------------- |
| `0` | Home                                                             |
| `1` | Feeds                                                            |
| `2` | Queue                                                            |
| `3` | Linkblog (unless you've deleted it)                              |
| `4` | Highlights                                                       |
| `5` | Discover                                                         |
| `6` | Manage Sources                                                   |
| `7` | Settings                                                         |
| `8` | the [review deck](/guide/saving-and-highlights/#the-review-deck) |

## Acting on an article

| Key | Does                                                                    |
| --- | ----------------------------------------------------------------------- |
| `s` | save, or unsave                                                         |
| `e` | archive a save, or bring it back to the inbox                           |
| `m` | mark read, or unread                                                    |
| `A` | mark everything in the feed you're looking at read                      |
| `t` | tag the item                                                            |
| `h` | highlight the paragraph, or remove its highlight                        |
| `F` | fetch the full article, when the feed sent only a summary               |
| `S` | share to your [linkblog](/guide/sharing-and-your-linkblog/), or unshare |

## In the reader

| Key       | Does                                              |
| --------- | ------------------------------------------------- |
| `c`       | show the article's **Contents**                   |
| `Shift +` | larger text, or zoom in on a PDF's original pages |
| `Shift -` | smaller text, or zoom out                         |
| `Shift 0` | reset the text size, or fit a PDF to the width    |

## Elsewhere

| Key   | Does                                               |
| ----- | -------------------------------------------------- |
| `a`   | open **Add to Skyreader**                          |
| `u`   | switch between unread and everything               |
| `?`   | show the shortcuts                                 |
| `Esc` | close an image or a dialog, or clear the selection |

The [review deck](/guide/saving-and-highlights/#the-review-deck) and [search](/guide/search/#shortcuts) have a few keys of their own, listed on their pages.
